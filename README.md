# 行迹 · Travel Journaling

单文件静态 Web 应用，用来把旅程、照片、地点和日记片段整理在一起。

## 本地预览

在项目根目录启动静态服务器：

    python -m http.server 8000

然后打开 http://localhost:8000。也可以直接打开 index.html；使用静态服务器时，本机存储的来源更稳定。

## 当前功能

- 创建、编辑多个旅程，并填写可选日期与目的地。
- 在旅程时间线添加、编辑和删除记忆；日期、地点、文字和照片均可留空。
- 选择 JPG、PNG、WebP 照片；浏览器会将图片缩小并保存在本机 IndexedDB，记忆字段保存在本机 localStorage。
- 按旅程浏览相册、日记文字和用户填写的区域。
- 依据已有记录生成可编辑游记草稿，并复制或下载为 TXT。
- 粘贴聊天推荐作为“待安排”记忆；目前没有聊天平台 API。
- 初始意大利旅程和其中照片是演示内容，可自行编辑或删除。

## 数据与能力边界

数据只存在于当前浏览器和当前设备，不会跨设备同步。清除浏览器站点数据可能删除日记副本；删除记忆不会删除设备相册里的原图。地点概览仅整理文字标签，不读取 GPS，也不提供地图路线。用户照片不上传；页面的演示照片和字体使用外部 CDN。
